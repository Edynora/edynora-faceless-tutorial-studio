# Architecture decisions

1. **2026-11-24: provider-independent deterministic core.** No model calls or subscription needed. TypeScript strict mode and Playwright Chromium native recording provide the shortest verifiable path. Browser Use, Stagehand and browser-harness remain research only. No inherited private profile access.
2. **Native recorder rather than bundled media stack.** Do not link OBS or ship a system FFmpeg. Playwright itself downloads an LGPL FFmpeg recorder and Chromium with mixed third-party notices. Keep these as upstream user-installed binaries. Document separate redistribution obligations. Use the user's ffprobe/FFmpeg only to validate development output.
3. **Viewport cursor.** Record SVG/DOM overlays rather than claim Windows mouse control. Match video and viewport size to avoid scaling offsets; device scale defaults to 1. Reduced motion supported.
4. **Single npm distribution, modular source.** Avoid workspace package publishing and a frontend until core acceptance is demonstrated. Packages folders are code boundaries rather than independently published modules. Node 24+ baseline.
5. **Explicit constrained plan.** Zod schemas and allowlisted actions; no eval or shell actions. Natural language remains a description/drafting input rather than executable browsing behavior. Cross-field checks remain runtime refinements.
6. **Conservative network and consent.** Exact origin allowlist, private-address filtering, redirect inspection, approved active actions for non-read requests. Fail closed on policy violations. Document DNS-rebinding and browser-routing limitations rather than claiming a secure proxy.
7. **Portable directory export.** JSON schemas + WebM + screenshot PNG + SHA-256 assets. No archive dependency. Version format `edynora-tutorial/1`; importer compatibility explicitly unverified. Original action values are not duplicated in export.
8. **Claude Code thin bridge.** Standard official .claude-plugin manifest, root commands/skills and a shell-free Node bridge to the built checkout selected by EDYNORA_STUDIO_ROOT. Validate and install with the actual Claude CLI. Do not incur a paid model call simply to test the deterministic adapter.
9. **Review fixes.** Abort and settle worker execution before serialization; narrow optional asset-manifest ENOENT handling; use CSP-compatible property masking; reject additional IPv6 special ranges; trigger visual rings on pointerdown and log only successful clicks. Regression tests cover each observed defect.
10. **Development licenses.** Pin a Vitest-compatible Vite 7 release rather than adopt Vite 8's unnecessary MPL CSS compiler. No CSS/React app is built. Re-audit the resulting tree and include bundled license sidecars in notices. The maintainer specified Copyright 2026 Edynora under Apache-2.0; do not infer registered entity status.
11. **Authorized source publication.** On November 24, 2026, the maintainer explicitly approved publishing the GitHub repository under Edynora. Preserve local recordings/configuration outside Git, sanitize diagnostic host paths, add repository links, and use GitHub private vulnerability reporting. This does not authorize npm publication, deployment or paid services.
